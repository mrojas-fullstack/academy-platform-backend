# Architecture Decision Records (ADR)

## Purpose

Architecture Decision Records (ADR) document important technical decisions made during the development of Academy Platform Backend.

Each ADR explains:

- The context.
- The decision.
- The consequences.
- The alternatives considered.

The objective is to preserve the reasoning behind architectural decisions and avoid repeating discussions in the future.

---

## Naming Convention

ADR files follow the format:

```
ADR-XXX-description.md
```

Example:

```
ADR-001-architecture.md
```

---

## Status

Possible states:

- Proposed
- Accepted
- Deprecated
- Superseded
